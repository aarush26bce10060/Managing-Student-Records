==================================================
              STUDENT RECORD PROJECT
==================================================

About the Project:
------------------
Hi! This is a simple Python program I made to manage student record details. 
It helps teachers or students store marks, calculate totals and grades, 
and keep track of attendance. All data gets saved in a text file so you 
don't lose it when you close the program!


Features:
---------
1. Add new student details (Roll No, Name, Marks, Attendance).
2. Automatically calculates Total Marks, Percentage, and Grade.
3. Show a list of all students saved in the system.
4. Search for a student using their Roll Number.
5. Saves everything into a text file named "students_data.txt".


Grading System Used:
--------------------
- 90% and above  : A+
- 80% to 89%     : A
- 70% to 79%     : B
- 60% to 69%     : C
- 50% to 59%     : D
- Below 50%      : Fail


How to Run the Code:
--------------------
1. Make sure you have Python installed on your computer.
2. Open your terminal or command prompt.
3. Go to the folder where you saved the code.
4. Run this command:
   
   python student_record.py


How to Use:
-----------
When you run the code, a menu will pop up with 5 options:

1. Add Student    --> Enter details for a new student.
2. Display All    --> View all stored student records.
3. Search Student --> Find a specific student by Roll No.
4. Save           --> Save current data to the file manually.
5. Exit           --> Save and exit the program.


Notes:
------
- If "students_data.txt" is missing on your computer, don't worry! 
  The program will automatically create a new file for you when you add a student.
- Written by me using basic Python concepts like Lists, Functions, File I/O, and Loops.
